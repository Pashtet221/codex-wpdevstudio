# Обновление записей wp-plugins от 2026-07-21

22 июля 2026 через `scripts/wp` были прочитаны и обновлены записи пользовательского типа `wp-plugins`, созданные 21 июля 2026.

## Обновленные плагины

| ID | Плагин | Что заполнено | Категории |
| --- | --- | --- | --- |
| 397 | Платные объявления HivePress | Добавлено описание для монетизации каталогов и досок объявлений HivePress. | Для маркетплейсов, Интеграции |
| 398 | Заказ в 1 клик для WooCommerce | Добавлено описание быстрого оформления заявки без длинного checkout. | Woocommerce |
| 399 | WooCommerce Subscriptions / рекуррентные платежи | Добавлено описание подписок и регулярных платежей для WooCommerce. | Woocommerce |
| 400 | Интеграция WordPress с CRM | Добавлено описание передачи заявок, заказов и лидов из WordPress в CRM. | Интеграции |

## Проверка

После обновления записи были повторно прочитаны через `scripts/wp get`, а назначение категорий проверено через WordPress REST API для post type `plugin`.

## Примечание по ACF-связям

Поля ACF `ps_plugin_related_plugins` и `ps_plugin_related_articles` были предварительно прочитаны через `scripts/wp acf`. Попытка записать relationship-поля через `scripts/wp update-acf` не изменила значения при payload по именам полей, а payload по ключам вернул ошибку `cwb_acf_update_failed`. Поэтому связанные плагины и статьи подобраны концептуально, но не записаны в ACF из-за ограничения текущего bridge-эндпоинта.
