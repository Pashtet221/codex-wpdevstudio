# Рекомендуемые плагины для записей — 2026-07-29

Проверены все 20 опубликованных записей типа `post` и все 12 опубликованных карточек типа `plugin`. Подбор для ACF relationship-поля `reboot_selected_related_posts` сохранён в `content/acf/post-recommended-plugins.json`; порядок ID отражает релевантность рекомендации.

Перед попытками изменения каждый объект записи был прочитан командой `scripts/wp get ID`, а его ACF — командой `scripts/wp acf ID`. После каждой тестовой записи результат повторно проверялся через `scripts/wp acf ID`.

## Ограничение API

На момент проверки Codex Bridge 0.3.0 не записывает relationship-поле:

- payload по имени поля с массивом ID возвращает успешный ответ, но значение после повторного чтения остаётся `null`;
- payload с оболочкой `fields` возвращает `cwb_acf_update_failed`;
- для 19 из 20 записей endpoint чтения ACF возвращает пустой список полей; само поле доступно только для записи 409.

Поэтому назначения подготовлены и проверены по существующим карточкам плагинов, но не считаются применёнными на сайте. Для фактической записи нужно исправить серверный endpoint Codex Bridge и убедиться, что группа `group_reboot_selected_related_posts` назначена всем записям типа `post`.
